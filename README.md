# 🎵 Music Player

A simple and responsive Music Player built using HTML, CSS, and JavaScript. This project provides a clean and minimal interface for playing and controlling music directly in the browser.

## ✨ Features

* ▶️ Play and pause music
* ⏭️ Skip to the next track
* ⏮️ Go back to the previous track
* 🎵 Display the current song
* 🔊 Control music playback
* ⏱️ Display music progress
* 📱 Responsive design
* 🎨 Simple and clean user interface

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* HTML Audio API
* DOM Manipulation
* CSS Flexbox
* Media Queries

---

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone YOUR-REPOSITORY-LINK
```

2. Open the project folder:

```bash
cd music-player
```

3. Open `index.html` in your browser.
